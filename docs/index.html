Assessment evidence quality

No confirmed finding without evidence.

A single-file tool whose database refuses to mark a finding confirmed until a hashed evidence row exists, then runs a deterministic gate over integrity, CVSS, proof, scope and secrets, and prints READY or NOT READY.

Download the latest release View the source

Enforced at the database

A trigger blocks confirmation without a hashed evidence row. The rule lives below the app, not in it.

Deterministic gate

Re-hashes evidence, recomputes CVSS against the first spec, checks proof, scope and secrets.

Single file

Standard-library Python. Clone it, run it, read the ledger. No services to stand up.

Honest by design

READY or NOT READY with a clear reason and an exit code, so it fits a pipeline.

How to use it. Initialize a ledger, add findings and hashed evidence, then run the gate before a package leaves your hands. See the repository for the commands and a worked example.
